# Automated Network Request Management in ServiceNow

## 📌 Project Overview

Automated Network Request Management in ServiceNow is a ServiceNow-based project designed to simplify and automate the management of network-related requests.

The project follows a structured five-phase development process, starting from requirement analysis and continuing through backend development, UI/UX customization, testing, security, deployment, and final documentation.

## 🎯 Objectives

- Automate network request management.
- Reduce manual processing of requests.
- Provide a structured request lifecycle.
- Improve request tracking and visibility.
- Implement backend automation in ServiceNow.
- Provide a user-friendly interface.
- Ensure proper testing and access control.

## 🛠️ Technologies Used

- ServiceNow
- JavaScript
- ServiceNow Server-Side Scripting
- GlideRecord
- Business Rules
- ServiceNow Workspace
- Kanban
- ServiceNow Tables and Forms
- Access Controls / Roles
